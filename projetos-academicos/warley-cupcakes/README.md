# Warley Cupcakes 🍰

Aplicação web desenvolvida como parte do Projeto Integrador Transdisciplinar II do curso de Engenharia de Software. A solução permite que usuários personalizem cupcakes escolhendo sabores, visualizando preços e finalizando pedidos de forma intuitiva e agradável.

## 📌 Objetivo

Criar uma plataforma funcional e acessível para personalização de cupcakes, utilizando ferramentas no-code, boas práticas de UX/UI, modelagem de dados e arquitetura MVC.

## 🚀 Tecnologias Utilizadas

- **Base44** – Plataforma no-code para desenvolvimento e hospedagem
- **HTML5 / CSS3 / JavaScript** – Interface visual e interativa
- **Python (conceitual)** – Lógica de backend simulada
- **MySQL** – Estrutura de banco de dados relacional
- **GitHub** – Versionamento e documentação
- **Pytest** – Testes unitários
- **YouTube** – Apresentação em vídeo

## 🧠 Arquitetura

A aplicação foi estruturada com base no padrão **MVC (Model-View-Controller)**:

- **Model:** Sabores, pedidos e clientes
- **View:** Interface visual com foco em usabilidade
- **Controller:** Lógica de personalização e fluxo de pedidos
