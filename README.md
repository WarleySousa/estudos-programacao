# Estudos de programação

Minha trilha de estudos desde a transição de carreira para a engenharia de software: exercícios de cursos, listas da faculdade e os primeiros projetos. Os projetos que mostram meu trabalho atual estão no [meu perfil](https://github.com/WarleySousa).

Cada pasta veio de um repositório separado, com o histórico de commits preservado.

| Pasta | Conteúdo | Linguagem |
| --- | --- | --- |
| [`python/curso-em-video`](python/curso-em-video) | Exercícios do curso de Python do Curso em Vídeo (`ex001` em diante). | Python |
| [`python/trilha-python-2026`](python/trilha-python-2026) | Trilha "do zero ao avançado" da Jornada de Dados: variáveis e tipos, estruturas de decisão e repetição, tratamento de erros. | Python |
| [`python/praticando`](python/praticando) | Primeiros exercícios e o primeiro uso de Git e GitHub. | Python |
| [`c/exercicios-ifmg`](c/exercicios-ifmg) | 10 listas de exercícios de programação em C da disciplina do IFMG. | C |
| [`java/primeiro-programa`](java/primeiro-programa) | Primeiro programa em Java. | Java |
| [`html-css/projeto-site`](html-css/projeto-site) | Site simples criado durante um curso de GitHub. | HTML · CSS |
| [`projetos-academicos/warley-cupcakes`](projetos-academicos/warley-cupcakes) | Documentação do Projeto Integrador Transdisciplinar II do curso de Engenharia de Software: aplicação no-code para personalizar e pedir cupcakes. | Base44 (no-code) |

## Como rodar

- **Python:** `python python/curso-em-video/ex001.py` (Python 3.10 ou mais novo).
- **C:** `gcc c/exercicios-ifmg/Pacote/lista-1/propostos/prop01-cap03.c -o prop01 && ./prop01`.
- **Java:** `javac java/primeiro-programa/src/primeiroprograma/PrimeiroPrograma.java`.
- **HTML/CSS:** abra `html-css/projeto-site/index.html` no navegador.
